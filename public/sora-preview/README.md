# Sora preview

A Sora-branded adaptation of ThreeUI Community’s Kage landing page, used as the active homepage. The immersive scene and chapter layout are preserved while the wordmark, page identity, and related Japanese name are being adapted.

- Source: https://github.com/MengTo/threeui
- Upstream file: `public/landing-pages/kage.html`
- License: MIT; see `LICENSE`.
- Preview page: `/sora-preview/sora.html`
- Homepage: `/`, rendered directly by `src/pages/index.astro` with asset URLs resolved under `/sora-preview/sora-world-assets/`.
- The older Galaxy modules remain in the repository as historical code.

Bundled fonts in `sora-world-assets/fonts.css` are embedded in the source stylesheet. Check the applicable font licenses before redistributing any extracted font files separately.
